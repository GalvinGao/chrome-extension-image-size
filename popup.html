File sizes, right on your images.

Enable first, then load images

Sizes are available only for images loaded AFTER monitoring is enabled. Reload this page after enabling to capture existing images.

Which size am I seeing?

The image file size after HTTP decompression (gzip or Brotli), not the compressed network transfer size.

JPEG, PNG, and WebP compression stays intact. This is not decoded bitmap memory.

No extra downloads. Chrome shows a debugging banner while monitoring.
