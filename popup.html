Image file size at a glance

Resource: file bytes after HTTP decompression. JPEG, PNG, and WebP compression stays intact.

Badge: encoded image file bytes, excluding headers. Cache checks do not shrink this value. If HTTP compression is present, this is the compressed file size.

Transferred in the details is the latest request’s actual transfer cost, which may be tiny or 0 B for cached images.

Hover or focus a label for dimensions, cache source, load time / TTFB, MIME type, resource size, and srcset availability.

Deep orange: 3–6 MB per displayed megapixel. Red: above 6 MB per displayed megapixel. Colors are based on resource bytes and displayed CSS dimensions. This is a heuristic, not a quality score.

No extra downloads. Chrome shows a debugging banner while monitoring.
